1. JavaScript là gì? Nó được dùng để làm gì trong thiết kế web?

Khái niệm: JavaScript (JS) là ngôn ngữ lập trình kịch bản thông dịch, đa mẫu hình (hướng sự kiện, hướng đối tượng dựa trên prototype), chạy trực tiếp trên trình duyệt web và cả phía máy chủ (Node.js). Cùng với HTML và CSS, JS là một trong ba công nghệ nền tảng của Web.

  • Tạo tính tương tác động: Xử lý sự kiện chuột, bàn phím, cuộn trang, menu thả xuống, slider ảnh.
  • Thao tác DOM theo thời gian thực: Thêm, sửa, xóa phần tử HTML và thay đổi CSS mà không cần tải lại trang.
  • Kiểm tra dữ liệu biểu mẫu (Form Validation): Xác thực dữ liệu nhập tại trình duyệt trước khi gửi lên máy chủ.
  • Giao tiếp bất đồng bộ: Sử dụng AJAX / Fetch API để cập nhật dữ liệu nền mượt mà.
  • Lưu trữ dữ liệu & ứng dụng web: Dùng LocalStorage, SessionStorage, phát triển SPA và mini game web.

2. Các kiểu dữ liệu chính trong JavaScript là những kiểu nào?

JavaScript chia thành 2 nhóm với 8 kiểu dữ liệu cơ bản (ES6+):

  • 7 kiểu dữ liệu nguyên thủy (Primitive): Number, BigInt, String, Boolean, Undefined, Null, Symbol.
  • 1 kiểu dữ liệu tham chiếu (Reference): Object (bao gồm cả Array, Function, Date, RegExp, Map, Set).

4. JavaScript có phải là ngôn ngữ lập trình đơn luồng không? Giải thích ngắn gọn.

Trả lời: Có, JavaScript là ngôn ngữ lập trình đơn luồng (Single-threaded).

Giải thích: Engine thực thi JS (như V8) chỉ có duy nhất một Call Stack nên tại một thời điểm chỉ thực thi tuần tự từng câu lệnh một. Để không làm treo giao diện khi chạy các tác vụ chờ (gọi API, setTimeout), JS kết hợp Web APIs của trình duyệt, hàng đợi Callback/Microtask Queue và cơ chế Event Loop để xử lý bất đồng bộ (Non-blocking).

5. Hàm (toán tử) delete trong JavaScript có tác dụng gì?

Toán tử delete dùng để xóa một thuộc tính (cả key và value) khỏi đối tượng (Object). Trả về true nếu xóa thành công hoặc thuộc tính không tồn tại; trả về false nếu thuộc tính không thể xóa. Khi dùng trên mảng (delete arr[i]), phần tử bị xóa để lại khoảng trống undefined và không làm thay đổi arr.length.

const sinhVien = { hoTen: "Lê Thái Bình", mssv: "241A010692", lop: "CNTT" };
delete sinhVien.lop; // true
console.log(sinhVien); // { hoTen: "Lê Thái Bình", mssv: "241A010692" }
